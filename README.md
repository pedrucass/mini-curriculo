## 📖 Sobre o Projeto

Bem-vindo ao repositório do meu currículo online! Este é um projeto pessoal que criei para me apresentar, compartilhar minha jornada na programação e exibir as tecnologias com as quais trabalho. A página foi desenvolvida do zero, utilizando **HTML5** e **CSS3**, com o objetivo de criar uma interface limpa, organizada e que refletisse minha identidade como desenvolvedor.

Minha paixão por programação começou aos 13 anos, e desde então venho evoluindo, passando da criação de mods para jogos até o desenvolvimento de soluções para servidores de GTA RP. Este site é um marco nesse caminho de aprendizado contínuo.

## ✨ Funcionalidades

*   **Apresentação Pessoal:** Uma seção que resume quem eu sou, minha idade, localização e aspirações.
*   **Links Sociais:** Acesso rápido ao meu GitHub, LinkedIn e YouTube.
*   **Exibição de Habilidades:** Uma lista organizada de minhas competências técnicas, incluindo linguagens, bancos de dados e ferramentas.
*   **Design Responsivo:** O layout foi pensado para se adaptar a diferentes dispositivos, garantindo uma boa experiência em desktops e celulares.

## 🚀 Tecnologias Utilizadas

*   **HTML5:** Para uma estrutura semântica, acessível e bem organizada.
*   **CSS3:** Para estilização, layout (Flexbox/Grid) e responsividade.
*   **Git & GitHub:** Para versionamento de código e hospedagem do projeto.

## 📚 Aprendizados e Desafios

Construir este projeto foi um excelente exercício para solidificar meus conhecimentos em front-end. Os principais aprendizados foram:

*   Estruturação de um projeto web do zero.
*   Uso de CSS para criar um layout harmonioso e fiel a uma ideia visual.
*   A importância de um HTML semântico para acessibilidade e SEO.
*   Prática de versionamento com Git, um pilar do desenvolvimento de software moderno.
